# M. Iftida Mushfiq Arnab — Portfolio Web Application

## 1. How to Open Locally (On Your Computer or Phone)
1. Extract `arnab_portfolio_deployable.zip`.
2. Double-click `index.html` (or `arnab_portfolio.html`) to open it directly in any web browser (Google Chrome, Microsoft Edge, Firefox, Brave, or Safari).

## 2. How to Deploy Live on the Web (Free)
- **Netlify Drop (Fastest, 30 seconds)**: Visit https://app.netlify.com/drop and drag-and-drop the extracted folder (or `arnab_portfolio_deployable.zip`) onto the page to get a live public URL immediately.
- **GitHub Pages**: Create a new repository on GitHub, upload `index.html`, and enable GitHub Pages under Settings -> Pages.
- **Vercel / Cloudflare Pages**: Import your repository or upload the folder to deploy globally.
